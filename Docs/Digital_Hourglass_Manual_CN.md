# 电子沙漏项目：CDIO 流程说明与操作指南

## 一、 项目概述
本说明书基于 CDIO（构思、设计、实现、运行）工程教育框架，详细说明了“数字 LED 电子沙漏”项目的技术可行性、工作流程及硬件操作指南。本项目的核心目标是制作一个具有精确计时功能，并通过翻转动作进行交互的电子设备。

## 二、 硬件选型与接线图 (详细步骤)
我们使用了 Arduino Uno R4 WiFi 作为主控，外接两个 MAX7219 8x8 点阵屏用于显示沙粒，一个 ICM20948 姿态传感器用于检测翻转，以及一个蜂鸣器用于听觉反馈。

请在断电状态下，严格按照以下步骤进行接线：

### 步骤 1：连接第一个点阵屏 (上方屏幕)
使用杜邦线，将 Arduino 的引脚与第一个 MAX7219 模块的 **输入端 (DIN 一侧)** 连接：
| Arduino Uno R4 WiFi 引脚 | MAX7219 (上方屏幕) 输入端 | 功能说明 |
| :--- | :--- | :--- |
| `5V` | `VCC` | 为屏幕提供 5V 电源 |
| `GND` | `GND` | 接地，形成闭合回路 |
| `Pin 11` | `DIN` | 数据输入线 (SPI MOSI) |
| `Pin 10` | `CS` (或 LOAD) | 片选线，激活数据接收 |
| `Pin 13` | `CLK` | 时钟线，同步数据传输速度 |

### 步骤 2：级联第二个点阵屏 (下方屏幕)
将第一个屏幕的 **输出端 (DOUT 一侧)** 与第二个屏幕的 **输入端 (DIN 一侧)** 使用短线连接，实现串联控制：
| MAX7219 (上方屏幕) 输出端 | MAX7219 (下方屏幕) 输入端 | 功能说明 |
| :--- | :--- | :--- |
| `VCC` | `VCC` | 共享电源 |
| `GND` | `GND` | 共享地线 |
| `DOUT` | `DIN` | 将指令向后传递给第二块屏幕 |
| `CS` (或 LOAD) | `CS` (或 LOAD) | 共享片选线 |
| `CLK` | `CLK` | 共享时钟线 |

### 步骤 3：连接 ICM20948 姿态传感器
该传感器通过 I2C 协议实时传输重力数据：
| Arduino Uno R4 WiFi 引脚 | ICM20948 传感器 | 功能说明 |
| :--- | :--- | :--- |
| `3.3V` (或 5V) | `VCC` (或 3V3 / +) | 供电 (推荐优先使用 3.3V) |
| `GND` | `GND` (或 -) | 接地 |
| `SDA` (或 A4) | `SDA` | I2C 数据传输线 |
| `SCL` (或 A5) | `SCL` | I2C 时钟同步线 |

### 步骤 4：连接蜂鸣器 (无障碍辅助硬件)
| Arduino Uno R4 WiFi 引脚 | 蜂鸣器模块 | 功能说明 |
| :--- | :--- | :--- |
| `Pin 9` | `SIG` (或 S) | 接收 Arduino 发出的频率信号 |
| `GND` | `GND` (或 -) | 接地 |
| `5V` (仅限三脚蜂鸣器) | `VCC` (或 +) | 供电 |

## 三、 包容性与无障碍设计 (Conceive & Design)
本项目的核心亮点之一是针对**视障群体（盲人友好）**的无障碍设计，体现了工程伦理与人文关怀：
1.  **交互确认反馈：** 当用户翻转沙漏重新开始计时时，蜂鸣器会发出清脆的“滴-滴”两声确认音。这为无法看清屏幕的用户提供了明确的操作成功反馈。
2.  **超时提醒机制：** 5 分钟倒计时结束后，设备会发出连续循环的警报音，直到用户感知并再次翻转设备。这使得沙漏具备了真正的实用定时器价值，不仅局限于视觉观赏。

## 四、 软件算法与核心逻辑 (Implement)
代码采用“非阻塞式”和“状态机”架构，确保设备稳定且响应迅速：
*   **精准计时算法：** 目标倒计时 5 分钟（300,000 毫秒）。单侧屏幕总计 64 颗“沙粒”(8x8 LED)。主控自动算出每颗沙粒掉落的时间间隔约为 **4,687 毫秒**。
*   **沙粒物理模拟：** 采用“粒子计数法”简化矩阵运算，动态维护上下沙粒总数 `topSandCount` 和 `bottomSandCount`。渲染引擎根据数量从下至上逐行点亮 LED，模拟沙子堆积。
*   **状态反转与中断：** 传感器后台以毫秒级频率轮询 Z 轴重力方向。检测到 180 度翻转后，瞬间对调上下屏幕的逻辑地址，清零计时器，并触发翻转提示音。
*   **非阻塞时间控制：** 彻底摒弃 `delay()`，全面采用 `millis()` 函数判断时间差。确保系统在鸣叫报警或等待沙子下落时，依然能零延迟捕获用户的下一次翻转动作。

## 五、 操作流程与展示指南 (Operate)
### 5.1 组装注意事项
1.  **屏幕对齐：** 在物理外壳中，两块屏幕必须严格垂直对齐，且确保排线正确级联。
2.  **传感器绝对固定：** 传感器模块必须使用螺丝或热熔胶**死死固定**在沙漏骨架上。传感器与屏幕的相对位置一旦发生松动，将直接导致翻转判定逻辑崩溃。

### 5.2 用户演示步骤
1.  **开机：** 接通 USB 电源，设备发出一声短促启动音，屏幕完成自检清空。
2.  **启动计时：** 将沙漏垂直放在桌面上。观众将看到上方的 LED 像素点每隔 4.68 秒消失一颗，并在下方屏幕底部出现一颗。
3.  **时间到：** 5 分钟后，屏幕沙子漏完，设备开始连续发出“滴——滴——滴——”的超时警报声。
4.  **互动翻转：** 邀请观众拿起沙漏，像真实沙漏一样翻转 180 度。设备立刻“滴滴”两声，警报戛然而止，倒计时完美重启。
