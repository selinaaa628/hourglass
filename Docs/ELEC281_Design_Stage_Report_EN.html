3. High-Level Software Flow Diagram (Finite State Machine)

The firmware operates on an asynchronous Finite State Machine (FSM). Time measurement is entirely non-blocking, guaranteeing sub-millisecond reaction times to orientation flips or key presses:

flowchart TD START(["Power-on / System Reset"]) --> INIT["BOOT_INIT\n- Initialize SPI, I2C, GPIOs, Keypad\n- Clear 6x MAX7219 Displays\n- Startup Chime tone(1000Hz, 200ms)"] INIT --> IDLE["IDLE_READY\n- Default timer set to 05:00\n- Rear display shows '05:00'\n- Await Keypad input OR Physical Flip"] %% Keypad branch IDLE -- "Key Pressed (0-9 or C)" --> SETTING["SETTING_MODE\n- Shift buffer left & append key\n- Audio click tone(2000Hz, 50ms)\n- Update rear preview (MMSS)\n- 'C' clears buffer to '0000'"] SETTING -- "Press '#' (Confirm)" --> COMMIT["Recalculate Duration\n- totalTimeMs = MM*60s + SS\n- dropInterval = totalTimeMs / 64\n- Confirmation beep tone(1500Hz)"] COMMIT --> IDLE %% Start Timing branch IDLE -- "Flip 180 deg (IMU Accel Z Inversion)" --> START_TIMING["TIMING_ACTIVE (Start)\n- Double-beep tone(1200Hz)\n- Reset sand (Top=64, Bottom=0)\n- Start timerStartTime = millis()"] SETTING -- "Flip 180 deg" --> START_TIMING %% Active timing loop START_TIMING --> LOOP{"Non-blocking Main Loop (millis)"} LOOP -- "millis() - lastDrop >= dropInterval" --> DROP["Drop Sand Grain\n- topSandCount--\n- bottomSandCount++\n- Refresh front LED matrices"] DROP --> LOOP LOOP -- "Every second" --> UPDATE_TIME["Update Rear Display\n- Calculate remaining MM:SS\n- Render digits on matrices 2-5"] UPDATE_TIME --> LOOP LOOP -- "180 deg Flip Detected mid-way" --> MID_FLIP["Mid-Flip Reversal\n- Swap Top and Bottom matrix IDs\n- Double-beep tone(1200Hz)\n- Restart countdown timer"] MID_FLIP --> LOOP %% Time Up branch LOOP -- "All sand dropped (topSand == 0)" --> DONE["ALARM_DONE (Time is Up!)\n- Rear display locks at '00:00'\n- Pulse alarm tone(800Hz) every 500ms\n- Await user acknowledgement"] DONE -- "Flip 180 deg (User Acknowledges)" --> START_TIMING
