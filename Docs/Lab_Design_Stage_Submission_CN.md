## 1. 硬件高层架构图 (Hardware Flow / Block Diagram)

硬件架构按照系统工程逻辑划分为：**供电系统**、**输入与感知系统**、**主控中枢 (MCU)**，以及**双向输出反馈系统 (视觉+听觉)**。

```mermaid
flowchart TD
    %% 供电源
    PWR["USB 5V 电源输入\n(电脑接口 / 移动电源)"] -->|"VUSB (5V)"| MCU["Arduino Uno R4 WiFi\n(R7FA4M1 主控芯片 / 48MHz)"]
    
    %% 供电分配
    MCU -->|"5V 电源总线 & 公共地"| DISP_PWR["5V 显示屏供电轨"]
    MCU -->|"3.3V 低压差线性稳压轨"| SENS_PWR["3.3V 低噪传感器供电轨"]

    %% 输入子系统
    subgraph Inputs ["输入与姿态感知子系统"]
        KP["4x4 薄膜矩阵键盘\n(用户自定义时长输入)"]
        IMU["ICM20948 / GY-87\n9轴/10轴运动姿态传感器\n(实时监测重力与翻转向量)"]
    end

    %% 总线连接
    KP -->|"8路 GPIO (引脚 2-8, 12)\n行列频闪扫描矩阵"| MCU

    SENS_PWR --> IMU

    %% 输出子系统
    subgraph Outputs ["多模态输出与交互子系统"]

            M2["MAX7219 8x8点阵 #1\n(下方玻璃沙泡)"]
        end
        subgraph VisualBack ["背面显示 (高精度 MM:SS 倒计时)"]
            M3["MAX7219 4合1点阵 #2..5\n(4位数字显示: MM:SS)"]
        end
        BUZ["无源蜂鸣器 (Passive Buzzer)\n(视障无障碍声音提示)"]

    %% SPI 级联总线
    MCU -->|"硬件 SPI 总线 (DIN=11, CS=10, CLK=13)"| M1

    M2 -->|"SPI 菊花链级联 (DOUT->DIN)"| M3

    MCU -->|"PWM 音频信号 (Pin 9, tone())"| BUZ
    MCU -->|"GND"| BUZ
```

### 硬件架构设计要点 (Design Highlights)
1. **电源分轨隔离 (Power Rail Isolation)**：MAX7219 点阵屏具有瞬间大电流特性，统一挂接在 Arduino 的 5V 电源总线上；精密惯性传感器 (IMU) 独立使用 3.3V 稳压轨供电，杜绝电压突降造成的传感器通讯死锁。
2. **高速 SPI 菊花链级联 (Daisy Chaining)**：系统共计 6 块 8x8 点阵屏（正面 2 块单屏 + 背面 1 块 4合1 屏），全部通过 SPI 协议的 DOUT $\rightarrow$ DIN 级联。仅耗费 3 根单片机引脚即可统一寻址 384 颗 LED，节约大量 I/O 资源。
3. **独立专用总线**：传感器独占硬件 I2C 总线，键盘使用 8 个通用 GPIO 进行行列快速扫描，彼此无物理与电气冲突。

## 2. 软件高层流程图 (Software Flow / State Machine Diagram)

软件架构采用基于非阻塞时间调度 (`millis()` 调度器) 的**有限状态机 (Finite State Machine, FSM)**，确保传感器轮询、按键扫描和沙粒掉落无任何卡顿。

```mermaid
flowchart TD
    START(["开机通电 / 系统复位"]) --> INIT["BOOT_INIT (初始化)\n- 初始化 SPI, I2C, GPIO, 键盘\n- 清空 6 块 MAX7219 点阵屏\n- 蜂鸣器短促启动音 tone(1000Hz, 200ms)"]
    INIT --> IDLE["IDLE_READY (待机就绪)\n- 默认时长设为 05:00\n- 背面屏幕显示 '05:00'\n- 待机监听按键 或 物理翻转"]

    %% 键盘输入分支
    IDLE -- "按下数字键 (0-9 或 C)" --> SETTING["SETTING_MODE (配置时长)\n- 缓冲区数字左移并存入按键值\n- 按键声音反馈 tone(2000Hz, 50ms)\n- 背面实时预览输入的 MMSS\n- 'C' 键一键清零为 '0000'"]
    SETTING -- "按下 '#' 键确认" --> COMMIT["重新换算倒计时时长\n- totalTimeMs = MM*60秒 + SS\n- dropInterval = totalTimeMs / 64\n- 确认提示音 tone(1500Hz)"]
    COMMIT --> IDLE

    %% 翻转启动分支
    IDLE -- "翻转 180 度 (Z轴重力突变)" --> START_TIMING["TIMING_ACTIVE (启动计时)\n- 滴-滴两声确认音 tone(1200Hz)\n- 重置沙粒 (上方=64, 下方=0)\n- 记录起始时间 timerStartTime = millis()"]
    SETTING -- "翻转 180 度" --> START_TIMING

    %% 核心运行循环
    START_TIMING --> LOOP{"非阻塞主循环调度器 (millis)"}
    
    LOOP -- "当前时间 - 上次掉落 >= dropInterval" --> DROP["掉落一颗沙粒\n- 上方沙粒数 topSand--\n- 下方沙粒数 bottomSand++\n- 刷新正面上下点阵屏"]
    DROP --> LOOP

    LOOP -- "每过一秒" --> UPDATE_TIME["刷新背面数字倒计时\n- 换算剩余分秒 (MM:SS)\n- 渲染到背面 4合1 点阵屏"]
    UPDATE_TIME --> LOOP

    LOOP -- "中途检测到 180 度翻转" --> MID_FLIP["中途翻转中断响应\n- 对调上下屏幕的显示映射\n- 滴-滴两声确认音 tone(1200Hz)\n- 重新开始新一轮倒计时"]
    MID_FLIP --> LOOP

    %% 计时结束分支
    LOOP -- "上方沙粒漏完 (topSand == 0)" --> DONE["ALARM_DONE (倒计时结束!)\n- 背面数字锁定显示 '00:00'\n- 蜂鸣器每隔 500ms 脉冲报警 tone(800Hz)\n- 持续等待用户翻转交互"]
    
    DONE -- "用户翻转 180 度解除警报" --> START_TIMING
```

### 软件设计核心优势 (Software Rationale)
* **完全非阻塞设计**：主循环体内彻底废除 `delay()`。按键消抖、蜂鸣器鸣叫和沙粒掉落全部采用时间差计算 (`millis() - previous >= interval`)，保证翻转动作零延迟响应。
* **自适应物理时间换算**：无论用户设定多长时间，代码动态换算单颗沙粒流动时间：
  $$\text{单颗掉落间隔 (dropInterval)} = \frac{\text{用户设定的总毫秒数 (totalTimeMs)}}{64\text{ 颗沙粒}}$$
* **无障碍与盲人友好交互**：开机、按键、确认、翻转和超时警报均配有专有频率的声音信号。

## 4. 实验课现场答辩与安全核对清单 (Pre-flight Checklist)
* **总线无冲突验证**：SPI（控制屏）、I2C（读取姿态）、PWM（控制声音）、GPIO（键盘）各自占用完全独立的硬件外设，零引脚冲突。
* **防短路规则**：接线前切记**拔掉电脑 USB**；绝不允许将 5V 误接至传感器的 3.3V 端口；杜邦线插好后轻轻扯动确认不松脱。
